## 1. 지금 이 게임은

쿼터뷰 3인칭 **실시간 액션 어드벤처**의 시제품입니다. 규칙 수치는 D&D SRD 5.2.1이고 그래픽은 저폴리(Quaternius)입니다.
"한 판"의 뼈대는 이렇습니다.

```
시작 화면 ─▶ 빈터 마을 ─▶ 3×3 지방(칸마다 자동 생성 지형) ─┬─ 몬스터 무리와 그 자리에서 싸움
 (이어하기/새로)   ▲  걸어서 경계 넘기 / 지도(M)로 빠른 이동  └─ 던전 입구 넷 ─▶ 던전 탐험 (층, 쉼터, 보물)
                  └──── 의뢰판: 무리 처치·우두머리·물건 찾기 ◀──────────────┘  첫 층 시작 칸에서 바깥으로
```

아직 없는 것: 평판과 조합 등급, 엔딩, 야영. → 마일스톤 M6~M7.

## 2. 해 볼 수 있는 것

`run.bat` 더블클릭 → 시작 화면.

| 어디 | 할 수 있는 것 | 조작 |
|---|---|---|
| 시작 화면 | 이어하기, 새로 시작(두 번 눌러 확인), 끝내기 | 마우스 |
| 마을 | 빈터 가운데 광장을 둘러싼 집 여섯 채쯤. 여관(10골드 하룻밤 = 긴 휴식 + 저장), 잡화점(물약), 모험가 조합 회관(가입은 M6), 의뢰판(오늘 붙은 의뢰 3개 받기, 끝낸 의뢰 보상, 소문), 돌아다니는 주민 | 문·의뢰판 앞에서 Enter / F / Y |
| 바깥 지형 | 3×3 지방, 칸마다 256×256칸 언덕·숲·절벽·바람 풀과 몬스터 무리 8곳. 칸 끝까지 걸으면 이웃 칸으로(1시간), 지방 끝은 언덕으로 막힘. 던전은 마을 칸 + 다른 칸 셋 | WASD, Space 점프, Q/E 카메라 90°, 휠 줌 |
| 바깥 전투 | 무리가 5칸 안에 오면 그 자리 지형 위에서 실시간 전투. 이기면 무리 사라짐, 14칸 떨어지면 도망, 지면 빈터에서 다시 | 공격 J/X, 구르기 Space/A, 기술 K/B, 기술2 L, 물약 1 |
| 던전 탐험 | 일직선 시야(6칸) 안개, 방마다 몬스터, 보물 상자, 모닥불(짧은 휴식), 쉼터(긴 휴식·물약 상인), 계단으로 층 오르내림 | 같은 조작, Enter 상호작용 |
| 의뢰 | 바깥 무리 처치 / 던전 N층 우두머리 / 던전 N층 물건 찾기. 한 번에 3개, 기한은 날짜(여관·쉼터에서 자면 하루). 끝내면 의뢰판에서 금화·경험치 | J: 일지 (바깥), 던전에서는 오른쪽 위 정보창 |
| 레벨업 | 1~5레벨, 4레벨 능력치 향상, 레벨마다 주문 고르기 | 창이 뜸 |
| 지도·시간 | 지도 창: 칸 이름, 마을·던전, ★ 의뢰, 걸리는 시간. 칸을 누르면 빠른 이동(이웃 6시간, 대각선 8.5시간), 던전 칸이면 입구 앞에 도착. 오른쪽 위 시계, 해가 지면 어두워짐 | M / 십자←, Esc 닫기 |
| 시험용 | B 단독 전투(F1~F8 조우), G 던전 생성기, H 시나리오 모드(「소금바람 저택」, 「꺼진 봉화」) | 바깥에서 키 |

저장: 1분마다, 장소를 옮길 때, 여관에서 묵을 때, 창을 닫을 때 자동 저장. 새 게임은 금화 30 (`%APPDATA%\Godot\app_userdata\2.5D Starter\save1.dat`).

## 5. 알려진 문제

- 바깥 전투·마을·의뢰·지방 지도: 직접 손으로 해 보지 않음 (자동 시험만 통과). 물가·아주 좁은 숲에서 자리가 모자랄 수 있음.
- 나무가 캐릭터를 가림 (던전 벽·마을 건물은 반투명 처리했지만 바깥 나무는 아직).
- 마을: 집 안에는 못 들어감(문 앞에서 창만 엶). 주민은 광장만 걸음.
- 의뢰 보상으로 레벨이 오르면 레벨업 고르기 창은 던전에 들어가야 뜸. 던전은 들어갈 때마다 새로 만들어져 우두머리도 다시 나옴.
- 칸을 넘거나 빠른 이동하면 장면을 다시 불러와 잠깐 멈춤(지형을 새로 만듦). 칸에 들어갈 때마다 물리치지 않은 무리는 그대로, 던전은 들어갈 때마다 새로 만들어짐.
- 싸움이 2~3초로 짧고 타격감(멈칫·소리)이 약함.
- 게임패드: 첫 화면(바깥)의 B/G/H와 던전 생성기 슬라이더는 키보드·마우스만.
- 프로젝트 이름이 아직 "2.5D Starter" (저장 폴더 이름이 이것을 따름).
