## 1. 지금 이 게임은

쿼터뷰 3인칭 **실시간 액션 어드벤처**의 시제품입니다. 규칙 수치는 D&D SRD 5.2.1이고 그래픽은 저폴리(Quaternius)입니다.
"한 판"의 뼈대는 이렇습니다.

```
시작 화면 ─▶ 빈터 마을 ─▶ 3×3 지방(칸마다 자동 생성 지형) ─┬─ 몬스터 무리와 그 자리에서 싸움
 (이어하기/새로)   ▲  걸어서 경계 넘기 / 지도(M)로 빠른 이동  └─ 던전 입구 넷 ─▶ 던전 탐험 (층, 쉼터, 보물)
                  └──── 의뢰판: 무리 처치·우두머리·물건 찾기 ◀──────────────┘  첫 층 시작 칸에서 바깥으로
```

처음부터 끝까지: 조합 가입 → 의뢰로 평판·레벨 올리기 → 베테랑 → 마지막 의뢰(가장 먼 던전 3층 우두머리) → 엔딩.
아직 없는 것: 야영, 전투 곡, 직접 플레이로 맞춘 밸런스. → M7 계속.

## 2. 해 볼 수 있는 것

`run.bat` 더블클릭 → 시작 화면.

| 어디 | 할 수 있는 것 | 조작 |
|---|---|---|
| 시작 화면 | 이어하기, 새로 시작(두 번 눌러 확인), 끝내기 | 마우스 |
| 마을 | 빈터 가운데 광장을 둘러싼 집 여섯 채쯤. 여관(10골드 하룻밤 = 긴 휴식 + 저장, 마을 평판으로 7·5골드), 잡화점(물약), 모험가 조합 회관(가입, 등급, 정회원부터 무료 하룻밤, 베테랑에게 마지막 의뢰), 의뢰판(오늘 붙은 의뢰 3개 받기, 끝낸 의뢰 보상, 소문), 돌아다니는 주민 | 문·의뢰판 앞에서 Enter / F / Y |
| 바깥 지형 | 3×3 지방, 칸마다 256×256칸 언덕·숲·절벽·바람 풀과 몬스터 무리 8곳. 칸 이름대로 숲은 빽빽하고 벌판은 낮고 트였으며 고개·언덕은 높음. 칸 끝까지 걸으면 이웃 칸으로(1시간), 지방 끝은 언덕으로 막힘. 던전은 마을 칸 + 다른 칸 셋 | WASD, Space 점프, Q/E 카메라 90°, 휠 줌 |
| 바깥 전투 | 무리가 5칸 안에 오면 그 자리 지형 위에서 실시간 전투. 이기면 무리 사라짐, 14칸 떨어지면 도망, 지면 빈터에서 다시 | 공격 J/X, 구르기 Space/A, 기술 K/B, 기술2 L, 물약 1 |
| 던전 탐험 | 일직선 시야(6칸) 안개, 방마다 몬스터, 보물 상자, 모닥불(짧은 휴식), 쉼터(긴 휴식·물약 상인), 계단으로 층 오르내림 | 같은 조작, Enter 상호작용 |
| 의뢰 | 바깥 무리 처치 / 던전 N층 우두머리 / 던전 N층 물건 찾기. 한 번에 3개, 기한은 날짜(여관·쉼터에서 자면 하루). 끝내면 의뢰판에서 금화·경험치 | J: 일지 (바깥), 던전에서는 오른쪽 위 정보창 |
| 레벨업 | 1~5레벨, 4레벨 능력치 향상, 레벨마다 주문 고르기 | 창이 뜸 |
| 평판·엔딩 | 의뢰 성공 +6 / 실패 −4 (우호 세력에 절반). 조합 등급: 견습(가입) → 정회원(조합 평판 15·2레벨) → 베테랑(35·3레벨). 비회원은 1층 의뢰만, 우두머리 의뢰는 회원만. 마지막 의뢰 보상을 받으면 엔딩 화면 | J 일지에 등급·평판 |
| 지도·시간 | 지도 창: 칸 이름, 마을·던전, ★ 의뢰, 걸리는 시간. 칸을 누르면 빠른 이동(이웃 6시간, 대각선 8.5시간), 던전 칸이면 입구 앞에 도착. 오른쪽 위 시계, 해가 지면 어두워짐 | M / 십자←, Esc 닫기 |
| 시험용 | B 단독 전투(F1~F8 조우), G 던전 생성기, H 시나리오 모드(「소금바람 저택」, 「꺼진 봉화」) | 바깥에서 키 |

저장: 1분마다, 장소를 옮길 때, 여관에서 묵을 때, 창을 닫을 때 자동 저장. 새 게임은 금화 30 (`%APPDATA%\Godot\app_userdata\tinySlash\save1.dat`, 예전 "2.5D Starter" 폴더의 저장은 처음 켤 때 옮겨 옴).

## 3. 시스템별 상태

| 시스템 | 상태 | 비고 |
|---|---|---|
| 규칙 엔진 (`rules/`) | ●●●● | SRD 12클래스 1~5레벨, 몬스터 20여 종, 주문·상태·저항. 테스트 250개 |
| 실시간 액션 전투 | ●●●○ | 던전·바깥 지형·시나리오 모두 같은 `ActionLayer`. 타격감: 히트스톱(멈칫), 흰 번쩍임, 몸 움찔, 불꽃, 화면 흔들림 (M7). 몬스터 HP 2배로 한 싸움 평균 4~5초(모의 전투, 승률 거의 100%, 잃는 HP 10~16%) |
| 던전 | ●●●○ | 생성기 3종(BSP·흩뿌리기·동굴), 지방에 이름 붙은 던전 넷(주제·방식 고정). 같은 던전·같은 층은 언제나 같은 구조, 비운 방·연 상자를 기억(비운 방은 3일 뒤 다시 참). 종류별 꾸밈 없음 |
| 바깥 지형 | ●●●○ | 3×3 지방, 칸 경계가 맞물리는 높이, 칸마다 성격(언덕 높이·숲 밀도). 물·늪·길은 없음 |
| 마을 | ●●○○ | 블록 격자 배치(`rules/village.gd`), Quaternius 조각으로 집 조립, 여관·상점·의뢰판 창. 상점은 물약뿐, 주민 대화 없음 |
| 저장 | ●●●○ | 파일 1개, 세계 시드 + 바뀐 것만. 저장 칸 여러 개 없음 |
| 파티 | ●●○○ | 주인공 + 동료 1 (클래스는 던전 생성기에서 고름). 캐릭터 만들기·장비 교체 없음 |
| 의뢰 | ●●○○ | 템플릿 4개, 빈칸 채우기, 진행·기한·보상, 저장. 구출·배달·대화 의뢰 없음 |
| 시간 | ●●○○ | 하루 주기와 빛, 여행·휴식에 드는 시간, 기한. 야영·습격 없음 |
| 평판·엔딩 | ●●○○ | 세력 둘, 조합 3등급과 혜택, 마지막 의뢰와 엔딩 화면. 세력이 더 없고 엔딩은 하나 |
| 소리 | ●●●○ | 효과음, 합성 바람·던전 환경음, 배경 음악 3곡(마을 가까이·들판·던전, `tools/install_music.sh`), 음량 설정(시작 화면·Esc 메뉴). 전투 곡 없음 |
| 턴제 전투 | 숨김 | T 키 뺌. 던전 생성기의 방 전투·시나리오 일부 코드에 남아 있음 |

## 5. 알려진 문제

- 바깥 전투·마을·의뢰·지방 지도·평판·엔딩: 직접 손으로 해 보지 않음 (처음부터 엔딩까지 몇 시간 걸리는지 모름, 4레벨까지 경험치가 많이 듦) (자동 시험만 통과). 물가·아주 좁은 숲에서 자리가 모자랄 수 있음.
- 나무가 캐릭터를 가림 (던전 벽·마을 건물은 반투명 처리했지만 바깥 나무는 아직).
- 마을: 집 안에는 못 들어감(문 앞에서 창만 엶). 주민은 광장만 걸음.
- 칸을 넘거나 빠른 이동하면 검은 화면 뒤에서 지형을 새로 만듦(1초쯤).
- 게임패드: 첫 화면(바깥)의 B/G/H와 던전 생성기 슬라이더는 키보드·마우스만.
